- ### 主要目标
  最大化在有限时间步 $T$ 内发现的目标数量：
  $$\max \sum_{t=1}^{T} \sum_{i=1}^{N} \mathbb{I}[\text{无人机 } i \text{ 在时间步 } t \text{ 发现新目标}]$$
  
  其中 $\mathbb{I}$ 是指示函数。
- ### 次要目标
  1. 最小化碰撞次数：
   $$\min \sum_{t=1}^{T} \sum_{i=1}^{N} \mathbb{I}[\text{无人机 } i \text{ 在时间步 } t \text{ 发生碰撞}]$$
  2. 最大化区域覆盖率：
   $$\max \frac{\text{已探索区域}}{\text{总区域}}$$
- 3. 最小化能源消耗：
- 4. 最小化能源消耗：
   $$\min \sum_{t=1}^{T} \sum_{i=1}^{N} E_i^t$$
   
   其中 $E_i^t$ 是无人机 $i$ 在时间步 $t$ 的能源消耗。
- ### 约束条件
  1. 无人机必须在环境边界内：
   $$x_{min} \leq x_i^t \leq x_{max}, \forall i, t$$
   $$y_{min} \leq y_i^t \leq y_{max}, \forall i, t$$
   $$z_{min} \leq z_i^t \leq z_{max}, \forall i, t$$
  2. 无人机之间必须保持最小安全距离以避免碰撞：
   $$|s_i^t - s_j^t| \geq d_{安全}, \forall i \neq j, \forall t$$
  3. 无人机的能源消耗不能超过最大能源限制：
   $$\sum_{t=1}^{T} E_i^t \leq E_{max}, \forall i$$
